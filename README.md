# CGS' Custom Keyboards
Este repositorio contiene una colección de teclados (en formato XKB) y reglas de `XCompose`, todo ello pensado principalmente para su uso en sistemas operativos libres compatibles con el formato XKB (Linux, FreeBSD, OpenBSD, NetBSD, Solaris, illumos, etc.).

![Ejemplo de uno de los teclados de la colección (Skorpian Master Keyboard (SMK) v16.0 [Variante Latina, QWERTY de España])](docs/images/SMK_Example.png)
